วิธีรัน api fastAPI 
python -m fastapi dev app/main.py

เช็คต่อ DB
python -c "from sqlalchemy import text; from app.core.database import engine; conn = engine.connect(); print('Connected:', conn.execute(text('SELECT 1')).scalar()); conn.close()"

ตัิดตั้งแพ็คเกจ python ด้วยไฟล์ requirements.txt
pip install -r requirements.txt

เริ่มต้นการใช้งาน alembic (ตัวหลังสุดคือตั้งชื่อโฟลเดอร์)
alembic init alembic

สร้าง Migration จาก Model อัตโนมัติ แล้วนำไปใช้กับฐานข้อมูล:
alembic revision --autogenerate -m "create shopmini tables"
alembic upgrade head
alembic current
